# 折叠屏开合动画模拟

在普通 Windows 笔记本上，用**自带的摄像头**识别上盖开合角度，实时复刻折叠屏（iPhone Duo 风格）的开合动画：桌面内容随开合做 **3D 透视折叠 + 磨砂模糊 + 渐变透明**，背景壁纸只模糊不变形，铺满整屏无黑场，全程跟手、任意角度悬停。

## 原理

1. **角度识别**：笔记本上盖的摄像头随开合绕转轴转动。程序用 ORB 特征匹配 + 单应矩阵分解，实时算出上盖相对基准帧的俯仰角，再映射为 0–180° 的折叠角。用「滑动关键帧 + 固定锚点校正」消除累计漂移，用 One Euro 滤波平滑抖动。
2. **渲染**：把实时抓取的桌面作为前景，做透视折叠 + 盒式模糊 + 渐变透明；背景用一张静态壁纸（只模糊不变形），铺满整屏无黑场。

## 环境

- Windows（带摄像头）
- Python 3.8+

```bash
pip install -r requirements.txt
```

依赖：`opencv-python`、`numpy`、`pygame`、`mss`

## 运行

```bash
python main.py
```

### 按键

| 键 | 作用 |
|---|---|
| `SPACE` | 标定基准帧（上盖完全展开时按下）+ 重新截屏 |
| `D` | 开关特征匹配调试窗口 |
| `R` | 翻转角度符号（方向反了按这个） |
| `+` / `-` | 调整灵敏度 SCALE |
| `B` | 开关绿色轮廓 |
| `F11` | 切换全屏 |
| `ESC` / `Q` | 退出（会写 timing_log.csv） |

### 使用步骤

1. 上盖**完全展开**，让摄像头对着**有纹理的静止场景**（墙、书架等，别对着纯白墙或自己）。
2. 运行 `python main.py`，按 `SPACE` 标定基准帧。
3. 慢慢开合上盖，屏幕内容就会跟着折叠。
4. 方向反了按 `R`，幅度不合适用 `+`/`-` 调 `SCALE`。

## 配置

- **背景图**：改 [renderer.py](renderer.py) 顶部的 `BACKDROP_PATH`（相对项目目录的文件名或绝对路径）。没有背景图时会自动用模糊压暗的桌面兜底。
- **模糊强度**：`max_blur`（前景模糊）、`BACKDROP_BLUR_SCALE`（背景相对前景的模糊比例）。
- **缩小幅度**：`project_panel` 里的 `scale = 1.0 - 0.3 * t`（`0.3` = 折叠到最小时缩到 0.7 倍）。

## 已知问题

- 摄像头必须用**上盖自带的那颗**（会随开合转动的），否则识别不到角度。
- 场景需要足够纹理，ORB 才能匹配到足够特征点。
- 屏幕分辨率较高时实时抓屏有一定开销，若卡顿可把 `render_scale` 调小（如 `0.4`）。
